# Закупки электротехники — страница

Страница раздела «Закупки» (по содержанию — каталог заявок на закупку электротехники) в визуальном стиле avtomatika.ru.

- Адаптив: десктоп (≥1180), планшет (768–1179), мобильный (<768)
- Темы: День, Ночь · Графит, Ночь · Чертёж (переключатель в шапке, запоминается; `?theme=` в URL)
- Поиск, категории, фильтры (статус, регион, тип заказчика, бюджет, дата), сортировка, пагинация, избранное
- Форма размещения заявки, FAQ
- `preview.html` — все три разрешения на одном экране

Чистый HTML/CSS/JS, без сборки.
